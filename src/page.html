01 · どこ？

新疆は、日本が4つ入るくらい広い

    03 · ウルムチ

    世界で一番、海から遠い大都市

    2,350km

    一番近い海（インド洋のベンガル湾）まで約2,350km。「世界で最も海から遠い大都市」としてギネス世界記録にも載っています。

    右の地図の赤い点線は、ウルムチから一番近い海までの距離で描いた円です。この円の中に、海はひとつもありません。日本はどこにいても海から約115km以内（一番遠いのは長野県佐久市）なので、20倍以上の遠さです。

    ユーラシア大陸で海から一番遠い地点（到達不能極）も、ウルムチの北約280kmにあります。地図の黄色い星がその場所です。

    ※ ギネスの記録では約2,500km。海岸線をどこまで細かく測るかで数字が変わります。

    名前の由来はモンゴル語で「美しい牧場」。人口は約405万人（2020年）で、高層ビルの向こうに雪山が見える街です。

    一番近い海までの距離の円点線の輪は1,000kmごと距離が正しく出る正距方位図法

    04 · 時差

    同じ街に、時計が2つある

    05 · ごはん

    羊と小麦と、甘い果物

    主役は羊肉と小麦。乾燥した気候と昼夜の寒暖差のおかげで、果物がとにかく甘いです。

    ラグメン 拌面 / Leghmen

    手で延ばしたコシの強い麺に、羊肉と野菜の炒め具をかけて混ぜて食べます。ウルムチっ子のソウルフード。

    ポロ 抓饭 / Polo

    羊肉、にんじん、玉ねぎを炊き込んだピラフ。お祝いの席の主役です。写真は東京・豊島区のお店のもの。

    大盤鶏 大盘鸡 / Dapanji

    鶏とじゃがいもをピリ辛に煮込んだ大皿料理。最後に幅広の麺をタレに絡めて食べるのがお約束。

    カワプ 羊肉串 / Kawap

    炭火で焼く羊の串焼き。味付けはクミンと唐辛子と塩だけ。夜市の煙の正体はこれです。

    ナン 馕 / Nan

    土窯で焼く丸くて平たいパン。インドのナンとは別物で、日持ちするので旅の携帯食にもなります。

    ブドウとハミ瓜 吐鲁番葡萄 / 哈密瓜

    トルファンのブドウとハミのメロンは中国中で有名。8〜9月は果物が一番おいしい季節です。

    06 · 自然

    雪山、湖、草原、砂漠が全部ある

    天山山脈が新疆を南北に分けていて、北は草原と湖、南は砂漠とオアシスの世界です。本物の標高データと衛星写真で作った3Dの新疆を、北のアルタイ山脈から南のパミール高原まで、季節の名所を巡りながら飛びます。スクロールで進みます。

    新疆の全体

    地形は実際の標高データ（高さは3.5倍に強調）。
    雪や紅葉の色は季節を表す演出です。

    07 · ことば・文化

    いろんな民族が一緒に暮らす街

    ウルムチにはウイグル族、漢族、カザフ族、回族など、いろいろな民族が暮らしています。街の看板はウイグル語と中国語の2つの文字で書かれています。

    音楽

    歌と踊りなしでは、何も始まらない

    ウイグルの古典音楽「ムカーム」と、歌と踊りの集まり「メシュレプ」は、どちらもユネスコの無形文化遺産です。写真はカシュガルの楽器店。カードの下には「日本でいうと、これに近い」楽器を並べました。

    ドゥタールدۇتار
    Dutar

    2本の弦をもつ長い棹の弦楽器。「ドゥ」はペルシャ語で「2」。歌の伴奏に一番よく使われます。

    日本でいうと三線（さんしん）

    長い棹で、素朴でやわらかい音。歌の伴奏が得意なところもそっくりです。

    ラワープراۋاپ
    Rawap

    胴に羊の皮を張った弦楽器。棹の付け根に角のような飾りがあり、明るく歯切れのよい音がします。

    日本でいうと三味線

    胴に皮を張り、ピック（撥）ではじいて鳴らす。キレのある音が似ています。

    タンブールتەمبۇر
    Tembur

    5本の弦をもつ、背の高い弦楽器。金属のピックで弾き、古典音楽ムカームの旋律を担当します。

    日本でいうと琵琶（びわ）

    フレットがあり、ピックで旋律を弾く。古典音楽の主役という立ち位置も同じです。

    ギジェクغىجەك
    Ghijek

    弓でこすって鳴らす楽器。人の声のように歌う音色で、ゆっくりした曲によく合います。

    日本でいうと胡弓（こきゅう）

    弓でこすって鳴らす、日本では数少ない擦弦楽器。泣くような音色が似ています。

    ダップداپ
    Dap

    内側に金属の輪がついた大きな枠太鼓。踊りのリズムを刻みます。写真は同じ形のウズベクの太鼓です。

    日本でいうとうちわ太鼓

    枠に皮を一枚張っただけの、手に持って打つ太鼓。ダップは輪がシャンシャン鳴ります。

    スナイسۇناي
    Sunay

    ダブルリードの管楽器で、とても大きな音が出ます。結婚式やお祭りの始まりの合図に欠かせません。写真は同じ仲間のスオナーです。

    日本でいうとチャルメラ

    ラーメン屋台の「チャラリ〜ラ〜」のあの楽器と同じ仲間です。

    今日使えるウイグル語

    ياخشىمۇسىزYaxshimusizヤフシムスィズこんにちは
    رەھمەتRehmetラフメットありがとう
    ياخشىYaxshiヤフシいいね、よい
    خوشXoshホシュさようなら
    مەن ياپونلۇقMen yaponluqメン ヤポンルク私は日本人です

    右がアラビア文字、左は上からラテン文字（ローマ字）、カタカナ読み、意味です。

    ウイグル語のこと

    正式な文字はアラビア文字で、右から左に書きます。パソコンやスマホ用にラテン文字（ローマ字）の書き方もあり、例えば「ありがとう」は رەھمەت ＝ Rehmet です。言葉としてはトルコ語やウズベク語の仲間で、語順は日本語と同じ「主語・目的語・動詞」なので、日本人には意外と覚えやすい言語です。

    08 · 行くなら

    地元民からのアドバイス

    6〜9月

    ベストシーズン

    草原が緑で、8〜9月は果物の季節。冬は−20℃を下回る日もありますが、天山でスキーができます。

    乗り継ぎ1回

    行き方

    日本からの直行便は基本的になく、北京や上海、西安などで国内線に乗り継ぎます。北京から約4時間です。

    移動は飛行機

    スケール感に注意

    新疆の中を移動するのも、国内線や長距離列車が基本です。1日に2カ所回るのは、ほぼ無理だと思ってください。

    09 · このページの作り方

    GitHubで見つけたもので作りました

    このページはスライドではなく、HTML 1枚です。Claude Codeと相談しながら、オープンソースのライブラリと公開データを組み合わせて作りました。途中であったことも含めて紹介します。

    1. スライドではなく「スクロールで読む地図と写真」にした

      HTMLCSSClaude Code

      話すときは画面を見せ、終わったあとはURLを配るだけで資料として残せる形にしたかったので、1枚のHTMLにしました。発表中は→←キーで章を移動できます。

    2. 写真はWikimedia CommonsのAPIで集めた

      Wikimedia CommonsMediaWiki API

      自分の写真がなかったので、自由に使える写真をAPIで検索しました。撮影者とライセンスも一緒に取得して、ページ下のクレジットはそのデータから作っています。

      途中から「429 Too Many Requests」で弾かれるようになりました。エラーページをよく読むと「元画像ではなく、決められたサイズのサムネイルを使ってください」と書いてあったので、1280px幅のサムネイルに変えたら全部取れました。エラーメッセージはちゃんと読むものですね。

    3. 地図の形はGitHubの公開データから

      dataofjapan/landDataV.GeoAtlas

      日本の形はGitHubの dataofjapan/land、新疆の形はDataV.GeoAtlasのGeoJSONを使いました。

      日本のデータは13MBもあったので、Douglas–Peucker法で点を間引いて約50KBにしました。最初は輪郭が「点2つ」になるバグが出ました。始点と終点が同じ「閉じた線」をそのまま処理していたのが原因です。

    4. 「本当の大きさ」で重ねるためにd3-geoを使った

      d3/d3-geoThe True Size Of

      よく見るメルカトル図法の地図は、北にある国ほど大きく見えます。そこで面積が正しく出る「正積方位図法」で、日本と新疆をそれぞれの中心から同じ縮尺で描いて重ねました。

      アイデアの元は、国を地図上で動かして本当の大きさを比べられる「The True Size Of」というサイトです。

    5. 動きはGSAPとCanvasで「映画っぽく」

      greensock/GSAPScrollTriggerCanvas

      雪はCanvasで描いた粒、タイトルは1文字ずつ浮かび上がり、地図は輪郭が光りながら描かれます。自然の章は、縦にスクロールすると写真が横に流れる「ピン留め」演出です。

      最初の版は「ちゃんとしてるけど地味」だったので、「もっとファンシーに」と頼んで作り直しました。動きを減らす設定（prefers-reduced-motion）の人には、演出を止めて静止画で見せています。

    6. 地球儀は、発表前日に思いついて足した

      topojson/world-atlasd3.geoOrthographicCanvas

      「東京からウルムチまでの時間を、地球の上で見せたい」と思って追加しました。世界の陸地はGitHubの world-atlas（Natural Earthのデータ）を使い、d3の正射図法で地球儀にしています。夜の影は、その時刻の太陽の位置を計算して描いています。

      d3に「2点を結ぶ線」を渡すと、自動で地球上の最短ルート（大圏コース）に曲げてくれます。線を引いてみたら、北京は東京とウルムチを結ぶ最短ルートのほぼ真上にあって、北京経由でも遠回りは約30kmしかありませんでした。作ってみて初めて気づいたことです。

    7. 新疆の3D地形は、本物の標高データと衛星写真で

      mrdoob/three.jsAWS Terrain TilesNASA Blue MarbleDecompressionStream

      GitHubで話題のブラウザ3Dゲームのように、新疆の上を飛べるようにしたくて作りました。標高はAWSで公開されている標高タイル（SRTMなど）、色はNASAの衛星写真「Blue Marble」です。three.jsで地面を作り、スクロールに合わせてカメラを動かしています。雪や紅葉の色は、シェーダーで重ねた季節の演出です。

      最初はスクロールの速さでカメラが一気に動き、「切り替えが速すぎる」と感じたので、行き先を決めると赤いヘリコプター（three.jsの図形を組み合わせた手作り）が数秒かけて飛んでいく方式に変えました。地図上の地名を押しても飛べます。

      標高タイル90枚をつなぐのに画像ライブラリ（Pillow）を使おうとしたら、入っていませんでした。そこでPythonの標準ライブラリだけでPNGを読むコードを書き、標高を4m単位の差分にしてzlibで圧縮。ブラウザ側は標準のDecompressionStreamで展開しているので、地形データ約37万点がライブラリなしで約500KBに収まりました。

    8. 公開はGitHub Pages

      GitHub Pages

      サーバーも、ビルドツールも、npmも使っていません。index.htmlと画像フォルダをリポジトリに置いて、Pagesをオンにするだけで公開できます。
